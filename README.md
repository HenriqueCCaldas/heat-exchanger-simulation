# heat-exchanger-simulation
Case Study for numerical simulation of a molten salt heat exchanger, under the TUM Case Study in Scientific Computing, Summer Semester 2024.<br/> 
**henrique** contains the research done by Henrique C. Caldas<br/>
**henrique/Heat_Exchanger_Simulation-Report.pdf** is the report with regards to the research done by Henrique C. Caldas, solely.<br/>
**henrique/Heat_Exchanger-Presentation.pdf** is the presentation contained the research done by Henrique C. Caldas, solely. <br/>
**henrique/pictures** contains the pictures used in the report and final presentation.<br/>
**henrique/shellTubeHex/shellTubeHex** contains the current simulation setup (to configure with SimFlow).<br/>
**henrique/shellTubeHex/results** contains the data analysis for the different scenarions considered on the simulation: water-water (with and without baffles for different velocities) and molten salt - oil (with baffles for different velocities).<br/>
**henrique/shellTubeHex/geometry** contains the geometry and baffles used for the simulations in SimFlow.<br/>
