# heat-exchanger-simulation
Case Study for Simulation of a Heat Exchanger. Old directory contains old files and simulations with different setups.
shelltubeHEX contains the current simulation setup (to configure with SimFLOW) and the data analysis for the different scenarions considered on the simulation: water-water (with and without baffles for different velocities) and molten salt - oil ( with baffles for different velocities).
