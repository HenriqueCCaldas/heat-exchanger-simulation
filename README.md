# heat-exchanger-simulation
Case Study for Simulation of a Heat Exchanger. 
henrique contains the research done by Henrique C. Caldas
henrique/Heat_Exchanger_Simulation-Report.pdf is the report with regards to the research done by Henrique C. Caldas, solely.
henrique/pictures contains the pictures used in the report and final presentation
henrique/shellTubeHex/shellTubeHex contains the current simulation setup (to configure with SimFlow). and the henrique/shellTubeHex/results contains the data analysis for the different scenarions considered on the simulation: water-water (with and without baffles for different velocities) and molten salt - oil (with baffles for different velocities).
henrique/shellTubeHex/geometry contains the geometry and baffles used for the simulations in SimFlow
